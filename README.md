# Mazad Online v2

نسخة جديدة ونظيفة من لعبة المزاد. الفئات: الأفلام، مشاهير ممثلين عالميين، والدول.

## الفئات
- 🎬 أفلام
- 🎭 مشاهير ممثلين عالميين
- 🌍 دول

فئة الدول تستخدم تقييمات لعبة من 100 في: الاقتصاد، السياحة، الأمان، البنية التحتية، جودة الحياة، الثقافة والتاريخ، الطبيعة، والترفيه. الأوزان: 20/15/15/10/10/10/10/10. التقييمات مخصصة لتوازن اللعبة وليست تصنيفًا رسميًا.

## تشغيل
```bash
npm install
npm start
```

## Render
استخدم متغيرات البيئة `SUPABASE_URL` و `SUPABASE_SERVICE_ROLE_KEY` إذا أردت الحسابات وحفظ النتائج.
